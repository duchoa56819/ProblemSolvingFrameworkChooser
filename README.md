## 🎯 Why This Tool Exists

When tackling difficult challenges, **choosing the wrong framework is worse than having no framework at all**:
- Applying linear root cause tools (**5 Whys**) to emergent, living human systems creates false certainty and finger-pointing.
- Imposing heavy statistical variance elimination (**DMAIC / Six Sigma**) on fast-moving early startup prototypes induces analysis paralysis.
- Deliberating over long-term strategic roadmaps (**MECE Trees**) during an active chaotic crisis (**OODA Loop / 8D Containment**) leads to disaster.

**Problem-Solving Framework Chooser** bridges this gap: it diagnoses your challenge in 60 seconds, calculates an affinity match across 24 proven frameworks, and provides **built-in interactive mini-tools** so you can execute immediately right in your browser.

## ✨ Key Features

### 1. 🧙‍♂️ Smart Framework Diagnostic Wizard
A 6-step diagnostic interrogator analyzing:
- **Nature of Challenge:** System glitch/defect, business strategy, user adoption/churn, engineering contradiction, operational waste, or backlog overload.
- **Problem Predictability:** Clear/repeatable, Complicated (expert analysis), Complex (emergent human patterns), or Chaotic (turbulent crisis).
- **Available Evidence:** Quantitative telemetry, qualitative interviews, technical schematics, or high ambiguity.
- **Timeframe & Urgency:** Flash triage (< 1 hr), sprint (1–2 days), strategic initiative (1–4 weeks), or continuous cadence.
- **Team Dynamics:** Solo contributor, tactical squad (2–6), cross-functional team (5–15), or executive boardroom.
- **Target Deliverable:** Root cause fix, tested prototype, ranked ROI backlog, strategic roadmap, or A3 consensus one-pager.

**Scoring Engine:** Calculates match affinity (up to 99%), surfaces runner-up alternatives, explains contextual reasons to consider them, and explicitly flags **methods to avoid** with failure-mode rationale.

---

### 2. 🗺️ 2D Problem Space Landscape Map
An interactive 2D scatter matrix mapping all 24 frameworks across two primary cognitive axes:
- **X-Axis:** *Analytical & Deductive Rigor* (0) ⟵ ⟶ *Creative & Generative Divergence* (100)
- **Y-Axis:** *Clear & Deterministic Order* (0) ⟵ ⟶ *Complex & Emergent Dynamics* (100)

Hover over any node for instant previews or click to view its complete playbook and interactive tool.

---

### 3. 🛠️ 7 Ready-to-Run Interactive Canvases
Don't just read about methodologies—run them instantly with zero setup:
1. **5 Whys Chain Generator:** Progressive interrogative ladder with root cause identification, Poka-Yoke countermeasure drafting, DRI ownership, and Markdown export.
2. **Ishikawa Fishbone (6M) Canvas:** Multi-variable root cause mapping across *Manpower, Machine, Method, Material, Measurement, and Milieu*.
3. **RICE & ICE Prioritization Calculator:** Quantify candidate roadmaps with `(Reach × Impact × Confidence) / Effort` and real-time auto-sorting leaderboards.
4. **Cynefin Sense-Making Litmus Matrix:** Interactive 4-quadrant navigator with domain-specific response postures (*Probe-Sense-Respond, Sense-Analyze-Respond, etc.*) and fatal trap warnings.
5. **Eisenhower Priority Matrix Board:** 4-quadrant task manager protecting high-leverage Quadrant 2 strategic deep work with a live *Q2 Health Ratio* indicator.
6. **SCAMPER Lateral Ideation Canvas:** 7 provocation mutation vectors (*Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse*) with starter prompts and notes.
7. **Toyota A3 Executive One-Pager:** Condense an entire complex corporate problem, baseline telemetry, root causes, countermeasures, and follow-up audits into an executive sheet.

## 🚀 Quick Start & Local Development

### Prerequisites
- Node.js `v18+` or `v20+` (Tested on `v22.14.0`)
- npm `v9+` or `v11+`

### Installation

```bash
# Clone the repository
git clone https://github.com/duchoa56819/ProblemSolvingFrameworkChooser.git

# Navigate to project directory
cd ProblemSolvingFrameworkChooser

# Install dependencies
npm install

# Start Vite local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
# Type check and build optimized bundle for production
npm run build

# Preview production build locally
npm run preview
```

The production output is generated in `./dist`.

## 🌐 Deploy to GitHub Pages

The repository includes a ready-to-use GitHub Actions workflow located at `.github/workflows/deploy.yml`.

To deploy:
1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. In your GitHub repository:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. Every push to `main` will automatically build and deploy the app to `https://duchoa56819.github.io/ProblemSolvingFrameworkChooser/`.
